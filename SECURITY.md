# Security policy

Faultline runs the `--check` command you give it through your shell, and
sends HTTP requests to the receiver you name. Only point it at systems you
own or are allowed to test.

## Reporting a vulnerability

Please **do not** open a public issue for security problems. Instead, use
GitHub's private reporting: on the repository's **Security** tab, choose
**Report a vulnerability**.

Include what you found, how to reproduce it, and its impact. You should get
a response within a week. We will agree on a fix and a disclosure date
with you before anything is made public.

## Supported versions

Only the latest commit on `main` receives security fixes until Faultline
has tagged releases.
